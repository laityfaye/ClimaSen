================================================================================
RAPPORT D'ANALYSE K-MEANS SST
Classification non supervisee des regimes de SST associes
aux evenements de precipitation extreme au Senegal (CHIRPS 1981-2023)
================================================================================

Date de generation : 2026-03-09
Donnees SST        : OISST v2 (1983-2023, resolution 0.25 deg, journalier)
Evenements         : extreme_events_phases_senegal.csv
                     (seuil >2 sigma sur anomalies standardisees CHIRPS)

================================================================================
1. METHODOLOGIE
================================================================================

1.1 Donnees d'entree
---------------------
- Champs SST globaux (OISST v2) : grille 60S-60N, 0-360 long, resolution 0.25 deg
  => 691 200 pixels SST par champ journalier
- Variable utilisee : anomalie SST (variable "anom" des fichiers NetCDF)
- Pour chaque evenement extreme, le champ SST du jour de l'evenement est extrait
- Periode : 1983-2023 (41 annees)

1.2 Pipeline de traitement
---------------------------
Etape 1 : Extraction des champs SST pour chaque evenement extreme
           par phase saisonniere
Etape 2 : Standardisation (StandardScaler, mean=0, std=1) de la matrice
           evenements x pixels
Etape 3 : Reduction dimensionnelle par ACP (PCA) pour retenir 95% de
           la variance expliquee
Etape 4 : Recherche du k optimal via criteres Elbow (inertie) + Silhouette
           sur la plage k=2..20
Etape 5 : K-Means final (random_state=42) sur les composantes PCA
Etape 6 : Reconstruction des centroides dans l'espace SST original
           (retroprojection PCA)

1.3 Separation par phase saisonniere
--------------------------------------
- Phase 1 (Debut)     : Mai - Juin
- Phase 2 (Pleine)    : Juillet - Aout
- Phase 3 (Fin)       : Septembre - Octobre

Un modele K-Means independant est entraine par phase, permettant d'identifier
les regimes SST specifiques a chaque periode de la saison des pluies sahelienne.

================================================================================
2. RESULTATS PAR PHASE
================================================================================

IMPORTANT - NOTE SUR LA METRIQUE "mean_max_precip"
----------------------------------------------------
La colonne `mean_max_precip` des fichiers cluster_characteristics.csv represente
la MOYENNE des precipitations maximales par evenement au sein de chaque cluster.
Pour un evenement donne, `max_precip` est la valeur maximale de precipitation
(mm/jour, CHIRPS) observee en un point de grille sur l'ensemble du territoire
senegala ce jour-la.

=> `mean_max_precip` d'un cluster  =/=  maximum absolu des precipitations

Les valeurs individuelles d'evenements peuvent depasser largement ces moyennes.
Les maximums absolus observes par phase (source : detection_report.txt) sont :
  - Phase 1 (Debut, Mai-Jun)     :  85.6 mm  (evenement individuel)
  - Phase 2 (Pleine, Jul-Aout)   : 231.4 mm  (evenement individuel)
  - Phase 3 (Fin, Sep-Oct)       : 102.5 mm  (evenement individuel)

L'evenement a 231.4 mm appartient a la Phase 2 mais ne concerne qu'1 seul
evenement sur 498 ; dilue dans la moyenne du cluster, il devient invisible.
Par ailleurs, les evenements les plus intenses en precipitation sont souvent
les plus localises spatialement : ils ont un rang bas dans le classement par
couverture et ne "dominent" pas les clusters SST.

Classification par intensite (toutes phases, 1317 evenements) :
  < 20 mm (modere)  : 210 evenements  (15.9%)
  20-50 mm          : 754 evenements  (57.3%)
  50-100 mm         : 335 evenements  (25.4%)
  >= 150 mm (extreme):  1 evenement   ( 0.1%)  <- le 231.4 mm

Les moyennes de clusters ci-dessous sont donc des valeurs centrales (P50 approx.)
et non des maxima. La variabilite intra-cluster peut etre tres elevee.

================================================================================
4. INTERPRETATION CLIMATOLOGIQUE
================================================================================

4.1 Structure commune a toutes les phases
-------------------------------------------
Dans chaque phase, le K-Means identifie systematiquement :
  (a) Un ou deux clusters dominants (50-75% des evenements) correspondant au
      regime SST "neutre" ou "moyen" de la periode : les evenements extremes
      se produisent dans toute configuration SST de fond.
  (b) Un cluster rare (<10%) concentre sur 1-2 annees, associe a un evenement
      ENSO majeur, avec les precipitations les plus intenses de la phase.
  (c) Des clusters intermediaires (10-30%) refletant la variabilite decennale
      des SST (rechauffement atlantique, transitions ENSO).

4.2 Role d'ENSO
----------------
La signature ENSO est visible dans les clusters rares de chaque phase :
  - Phase 1, Cluster 3 : centree en 1997 => El Nino 1997-98 (fort)
  - Phase 2, Cluster 4 : centree en 2010-11 => La Nina 2010-11 (fort)
  - Phase 3, Cluster 4 : centree en 1998-99 => La Nina 1998-99 (post El Nino)

Ces annees sont connues comme des annees de precipitation exceptionnelle au
Sahel/Senegal. Le K-Means les capture sans supervision, ce qui valide la
pertinence de l'approche.

4.3 Contraste intensite vs extension spatiale
----------------------------------------------
En pleine saison (Phase 2), le Cluster 2 (le plus intense, 61 mm) est celui
avec la PLUS FAIBLE couverture spatiale (17.6%). Cela suggere que les evenements
les plus extremes en juillet-aout sont des MCS convectifs tres intenses mais
localises, contrairement aux evenements moderes qui couvrent plus de surface.
Ce contraste est moins marque en debut et fin de saison.

4.4 Dimension temporelle (annee moyenne par cluster)
-----------------------------------------------------
Les annees moyennes par cluster tracent une evolution implicite :
  - Phase 1 : clusters dominants centres 2002-2006 (milieu de periode)
  - Phase 2 : clusters dominants centres 2000-2007
  - Phase 3 : cluster dominant centre 2002-2004

Il n'y a pas de tendance claire vers des annees tres recentes dans les clusters
dominants, coherent avec l'absence de signal de trend significatif dans les
teleconnexions (rapport teleconnexions, FDR non significatif).

4.5 Limites de l'analyse
-------------------------
  - Les centroides K-Means sont exprimes dans l'espace PCA ; leur interpretation
    directe en termes de patterns SST spatiaux necessite la retroprojection
    (voir figures 04_cartes_sst_centroides.png).
  - Le critere Elbow peut etre ambigu ; le k optimal est un compromis entre
    inertie et interpretabilite.
  - Les clusters "rares" (n<20) ont une interpretation limitee par le faible
    effectif ; leur centroide est sensible aux annees extremes.
